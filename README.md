# yt-downloader

โปรแกรมโหลดคลิปจาก YouTube ลงเครื่อง ได้ทั้ง **วิดีโอ (MP4)** และ **เสียงอย่างเดียว (MP3 หรือ WAV)**
ไฟล์ที่โหลดเสร็จจะไปอยู่ในโฟลเดอร์ **Downloads**

**ต้องมี:** เครื่อง Mac, โปรแกรม **Google Chrome** (ถ้ายังไม่มี โหลดได้ที่ [google.com/chrome](https://www.google.com/chrome/)) และบัญชี YouTube (Gmail) ของตัวเอง

**ใช้เวลา:** ตั้งค่าครั้งแรกประมาณ 10–15 นาที ทำแค่ครั้งเดียว หลังจากนั้นเปิดโปรแกรมแล้วโหลดได้เลย

ทำตามทีละข้อ ไม่ต้องรีบ ถ้าติดตรงไหนให้แคปหน้าจอส่งมาถามได้

---

## ส่วนที่ 1: ติดตั้งแอป (ทำครั้งเดียว)

### ขั้น 1 — ดูว่า Mac ใช้ชิปอะไร

1. คลิกรูป **แอปเปิ้ล ** มุมซ้ายบนสุดของจอ
2. เลือก **About This Mac** (เกี่ยวกับ Mac เครื่องนี้)
3. ดูบรรทัด **Chip** หรือ **Processor**

### ขั้น 2 — โหลดแอป

กดลิงก์ให้ตรงกับชิปของเครื่อง:

| ถ้าเห็นคำว่า | กดโหลดอันนี้ |
|---|---|
| Apple M1, M2, M3, M4 | **[โหลดสำหรับ Apple Silicon](https://github.com/Tontae/youtube-downloader/releases/latest/download/yt-downloader-mac-AppleSilicon.zip)** |
| Intel | **[โหลดสำหรับ Intel](https://github.com/Tontae/youtube-downloader/releases/latest/download/yt-downloader-mac-Intel.zip)** |

(ไฟล์ประมาณ 180 MB รอโหลดสักครู่ ถ้าโหลดตัวผิด แอปจะเปิดไม่ขึ้น ให้กลับมาโหลดอีกตัว)

### ขั้น 3 — แตกไฟล์และย้ายแอป

1. เปิดโฟลเดอร์ **Downloads** ดับเบิลคลิกไฟล์ **.zip** ที่เพิ่งโหลด จะได้ไอคอน **yt-downloader** ออกมา (บางเครื่องแตกไฟล์ให้เองแล้ว)
2. เปิด **Finder** (ไอคอนหน้ายิ้มสีฟ้าใน Dock ด้านล่างจอ)
3. ลากไอคอน **yt-downloader** ไปวางที่ **Applications** แถบซ้ายมือของ Finder

### ขั้น 4 — ปลดล็อกให้ Mac ยอมเปิดแอป (ทำครั้งเดียว)

แอปนี้ทำใช้กันเอง ไม่ได้ลงทะเบียนกับ Apple ถ้าไม่ทำขั้นนี้ Mac จะขึ้นว่าแอปเสียหรือเปิดไม่ได้

1. กดปุ่ม **Command (⌘) + Space** พร้อมกัน จะมีช่องค้นหาโผล่กลางจอ
2. พิมพ์ **Terminal** แล้วกด **Enter** จะมีหน้าต่างตัวหนังสือเล็ก ๆ เปิดขึ้นมา (ไม่ต้องตกใจ)
3. คัดลอกบรรทัดข้างล่างนี้ทั้งบรรทัด แล้ววางในหน้าต่างนั้น (กด **⌘ + V**)

   ```
   xattr -cr /Applications/yt-downloader.app
   ```

4. กด **Enter** ถ้าไม่มีข้อความอะไรขึ้นมา แปลว่าสำเร็จแล้ว
5. ปิด Terminal ได้เลย

### ขั้น 5 — เปิดแอป

1. เข้า Finder → **Applications** → ดับเบิลคลิก **yt-downloader**
2. ถ้ายังขึ้นเตือนว่าเปิดไม่ได้: คลิก  → **System Settings** → **Privacy & Security** → เลื่อนลงล่าง → กด **Open Anyway** แล้วเปิดแอปใหม่
3. ตอนเปิดครั้งแรก จะขึ้น **"กำลังตรวจสอบและอัปเดต yt-dlp..."** รอสักครู่ (ไม่เกิน 15 วินาที) เป็นเรื่องปกติ

## ส่วนที่ 2: ใส่ไฟล์คุกกี้ (ทำครั้งแรก และทำซ้ำเมื่อโหลดไม่ได้)

YouTube ไม่ให้โปรแกรมโหลดคลิปถ้าไม่ได้ล็อกอิน เลยต้องใช้ "ไฟล์คุกกี้" ซึ่งเป็นเหมือนบัตรผ่านจากบัญชี YouTube ของเรา

### ขั้น 1 — ติดตั้งตัวช่วยใน Chrome

1. เปิด Chrome แล้วค้นใน Google ว่า **Get cookies.txt LOCALLY**
2. กดเข้าหน้า Chrome Web Store ของตัวนั้น → กด **Add to Chrome** → กด **Add extension**
3. คลิกไอคอน **จิ๊กซอว์ 🧩** มุมขวาบนของ Chrome → กดรูป **เข็มหมุด** ข้าง Get cookies.txt LOCALLY ให้มันโผล่บนแถบตลอด

### ขั้น 2 — ล็อกอิน YouTube

1. ใน Chrome เข้า **youtube.com**
2. ดูมุมขวาบน ถ้าเห็นปุ่ม **Sign in** ให้กดแล้วล็อกอินด้วย Gmail ของตัวเอง (ถ้าเห็นรูปโปรไฟล์แล้ว ข้ามได้)

### ขั้น 3 — สร้างไฟล์คุกกี้

1. ขณะอยู่ที่หน้า youtube.com คลิกไอคอน **Get cookies.txt LOCALLY**
2. กดปุ่ม **Export**
3. จะได้ไฟล์ชื่อประมาณ **cookies.txt** อยู่ในโฟลเดอร์ **Downloads**

### ขั้น 4 — ใส่ไฟล์ในแอป

1. กลับมาที่ yt-downloader → กดปุ่ม **"เลือกไฟล์ cookies.txt"**
2. เลือก **Downloads** → คลิกไฟล์คุกกี้ที่เพิ่งได้ → กด **Open**
3. แอปจะขึ้นว่า **"บันทึกไฟล์คุกกี้แล้ว พร้อมใช้งาน"** เป็นอันเสร็จ

> ⚠️ **ห้ามส่งไฟล์คุกกี้ให้ใคร** ใครได้ไฟล์นี้ไปจะเข้าบัญชี YouTube/Gmail ของเราได้ ใส่ในแอปเสร็จแล้ว ลบไฟล์ใน Downloads ทิ้งได้เลย (แอปเก็บสำเนาไว้ให้แล้ว)

## ส่วนที่ 3: โหลดคลิป (ทำทุกครั้งที่ใช้)

1. **คัดลอกลิงก์:** เปิดคลิปใน YouTube → กด **Share (แชร์)** ใต้คลิป → กด **Copy (คัดลอก)**
   - หรือคลิกที่ช่องที่อยู่เว็บด้านบน แล้วกด **⌘ + C**
2. **วางลิงก์:** ในแอป คลิกช่อง **"ลิงก์วิดีโอ"** → กด **⌘ + V**
3. กดปุ่ม **"ดึงข้อมูล"** แล้วรอสักครู่ จะเห็นชื่อคลิปขึ้นมา
4. กดช่อง **"ความละเอียด / ไฟล์เสียง"** แล้วเลือกตามตารางข้างล่าง
5. กดปุ่ม **"ดาวน์โหลด"** แล้วรอแถบสีวิ่งจนเต็ม
6. เมื่อขึ้น **"ดาวน์โหลดเสร็จแล้ว"** เปิด Finder → **Downloads** จะเจอไฟล์ที่ชื่อเหมือนชื่อคลิป

| อยากได้ | เลือก |
|---|---|
| วิดีโอคมชัด | ตัวเลขมากสุด เช่น **1080p (mp4)** (ตัวเลขยิ่งมาก ยิ่งชัด แต่ไฟล์ใหญ่และรอนานกว่า) |
| วิดีโอไฟล์เล็ก โหลดเร็ว | **720p** หรือ **480p** |
| เพลง / เสียงไว้ฟัง | **เสียงอย่างเดียว — MP3** |
| เสียงไว้ตัดต่องาน (ไฟล์ใหญ่กว่า MP3 ประมาณ 10 เท่า) | **เสียงอย่างเดียว — WAV** |

ถ้าคลิปยาว ปุ่มโหลดจะขึ้น **"กำลังแปลงไฟล์ให้เข้ากับโปรแกรมตัดต่อ..."** ตอนท้าย ให้รอจนเสร็จ อย่าปิดแอป

## ถ้าเจอปัญหา

| เจออะไร | ทำแบบนี้ |
|---|---|
| เปิดแอปไม่ได้ ขึ้นว่าแอปเสีย หรือ "cannot be opened" | ทำ **ส่วนที่ 1 ขั้น 4** (คำสั่งใน Terminal) อีกครั้ง แล้วเปิดใหม่ |
| เคยโหลดได้ แต่วันนี้ขึ้น "ดาวน์โหลดไม่สำเร็จ" หรือ "ดึงข้อมูลไม่สำเร็จ" | คุกกี้หมดอายุ ทำ **ส่วนที่ 2 ขั้น 3** ใหม่ แล้วใส่ไฟล์คุกกี้ใหม่ในแอป |
| ขึ้นว่า "ไม่พบไฟล์คุกกี้" | ทำ **ส่วนที่ 2** ทั้งหมด |
| ค้างที่ "กำลังตรวจสอบและอัปเดต yt-dlp..." นานเกิน 15 วินาที | เช็คว่าเน็ตต่ออยู่ แล้วปิดเปิดแอปใหม่ |
| ขึ้นว่ามีการดาวน์โหลดกำลังทำงานอยู่ | รอให้ตัวเดิมเสร็จก่อน |
| ใส่ลิงก์ Playlist แล้วได้คลิปเดียว | ปกติ แอปโหลดทีละคลิป ต้องใส่ลิงก์ทีละคลิป |
| ลองหลายอย่างแล้วยังไม่ได้ | แคปหน้าจอ (**⌘ + Shift + 4** แล้วลากคลุมส่วนที่ต้องการ) ส่งมาให้คนที่ส่งแอปให้ |

ส่วนใหญ่ปัญหามาจากคุกกี้หมดอายุ ถ้าวันหนึ่งโหลดไม่ได้ ให้ลองทำ **ส่วนที่ 2** ใหม่ก่อนเสมอ

## สำหรับนักพัฒนา

แอป Electron ที่เรียก [yt-dlp](https://github.com/yt-dlp/yt-dlp) และ [ffmpeg](https://ffmpeg.org/) ซึ่ง bundle อยู่ใน `bin/` (ไม่ได้ commit ไว้)

- Windows: วาง `yt-dlp.exe` และ `ffmpeg.exe` ใน `bin/` แล้ว `npm ci` → `npm start` หรือ `npx electron-builder --win`
- macOS: build ผ่าน GitHub Actions (`.github/workflows/build-mac.yml`) ทั้ง arm64 และ x64 ไฟล์ zip อยู่ใน artifacts ของแต่ละ run
