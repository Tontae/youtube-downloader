# yt-downloader

โปรแกรมโหลดคลิปจาก YouTube ลงเครื่อง ได้ทั้ง **วิดีโอ (MP4)** และ **เสียงอย่างเดียว (MP3 หรือ WAV)**
ไฟล์ที่โหลดเสร็จจะไปอยู่ในโฟลเดอร์ **Downloads**

**ต้องมี:** โปรแกรม **Google Chrome** (ถ้ายังไม่มี โหลดได้ที่ [google.com/chrome](https://www.google.com/chrome/)) และบัญชี YouTube (Gmail) ของตัวเอง

**ใช้เวลา:** ตั้งค่าครั้งแรกประมาณ 10–15 นาที ทำแค่ครั้งเดียว หลังจากนั้นเปิดโปรแกรมแล้วโหลดได้เลย

ทำตามทีละข้อ ไม่ต้องรีบ ถ้าติดตรงไหนให้แคปหน้าจอส่งมาถามได้

## เลือกเวอร์ชัน

|---|---|---|
| Windows 10 / 11 | **[yt-downloader-windows.zip](https://github.com/Tontae/youtube-downloader/releases/latest/download/yt-downloader-windows.zip)** | [ติดตั้งบน Windows](#ติดตั้งบน-windows) |
| Mac ชิป Apple M1, M2, M3, M4 | **[yt-downloader-mac-AppleSilicon.zip](https://github.com/Tontae/youtube-downloader/releases/latest/download/yt-downloader-mac-AppleSilicon.zip)** | [ติดตั้งบน Mac](#ติดตั้งบน-mac) |
| Mac ชิป Intel | **[yt-downloader-mac-Intel.zip](https://github.com/Tontae/youtube-downloader/releases/latest/download/yt-downloader-mac-Intel.zip)** | [ติดตั้งบน Mac](#ติดตั้งบน-mac) |

ไม่รู้ว่า Mac ใช้ชิปอะไร: คลิกรูป **แอปเปิ้ล ** มุมซ้ายบนสุดของจอ → **About This Mac** → ดูบรรทัด **Chip** หรือ **Processor**
ถ้าเห็น "Apple M…" ใช้ตัว AppleSilicon ถ้าเห็น "Intel" ใช้ตัว Intel (โหลดผิดตัว แอปจะเปิดไม่ขึ้น ให้กลับมาโหลดอีกตัว)

ไฟล์ละประมาณ 180–200 MB รอโหลดสักครู่

ติดตั้งเสร็จแล้ว ไปต่อที่ [ใส่ไฟล์คุกกี้](#ใส่ไฟล์คุกกี้-ทำครั้งแรก-และทำซ้ำเมื่อโหลดไม่ได้) แล้วก็ [โหลดคลิป](#โหลดคลิป-ทำทุกครั้งที่ใช้) — สองส่วนนี้ทำเหมือนกันทั้ง Windows และ Mac

เลิกใช้แล้ว ดู [ถอนการติดตั้ง](#ถอนการติดตั้ง)

## ติดตั้งบน Windows

### ขั้น 1 — แตกไฟล์

1. เปิดโฟลเดอร์ **Downloads** คลิกขวาที่ไฟล์ **yt-downloader-windows.zip** → เลือก **Extract All... (แยกไฟล์ทั้งหมด)**
2. ตรงช่องที่อยู่ เปลี่ยนเป็นโฟลเดอร์ **Documents (เอกสาร)** หรือ **Desktop** ก็ได้ แล้วกด **Extract**
   - **อย่าวางไว้ใน `Program Files`** แอปต้องเขียนไฟล์ลงโฟลเดอร์ของตัวเอง ถ้าวางที่นั่นจะใส่คุกกี้และอัปเดตไม่ได้
3. จะได้โฟลเดอร์ **yt-downloader** ข้างในมีไฟล์ **yt-downloader.exe**

### ขั้น 2 — เปิดแอป

1. ดับเบิลคลิก **yt-downloader.exe**
2. ถ้าขึ้นหน้าจอสีฟ้า **"Windows protected your PC"** (เป็นเพราะแอปทำใช้กันเอง ไม่ได้ซื้อใบรับรองจาก Microsoft)
   กด **More info** → กด **Run anyway** (ทำครั้งเดียว ครั้งต่อไปไม่ถามแล้ว)
3. ตอนเปิด จะขึ้น **"กำลังตรวจสอบและอัปเดต yt-dlp..."** รอสักครู่ (ไม่เกิน 15 วินาที) เป็นเรื่องปกติ

**อยากเปิดง่าย ๆ ครั้งหน้า:** คลิกขวาที่ **yt-downloader.exe** → **Show more options** → **Send to** → **Desktop (create shortcut)** จะได้ไอคอนบนหน้าจอ

## ติดตั้งบน Mac

### ขั้น 1 — แตกไฟล์และย้ายแอป

1. เปิดโฟลเดอร์ **Downloads** ดับเบิลคลิกไฟล์ **.zip** ที่เพิ่งโหลด จะได้ไอคอน **yt-downloader** ออกมา (บางเครื่องแตกไฟล์ให้เองแล้ว)
2. เปิด **Finder** (ไอคอนหน้ายิ้มสีฟ้าใน Dock ด้านล่างจอ)
3. ลากไอคอน **yt-downloader** ไปวางที่ **Applications** แถบซ้ายมือของ Finder

### ขั้น 2 — ปลดล็อกให้ Mac ยอมเปิดแอป (ทำครั้งเดียว)

แอปนี้ทำใช้กันเอง ไม่ได้ลงทะเบียนกับ Apple ถ้าไม่ทำขั้นนี้ Mac จะขึ้นว่าแอปเสียหรือเปิดไม่ได้

1. กดปุ่ม **Command (⌘) + Space** พร้อมกัน จะมีช่องค้นหาโผล่กลางจอ
2. พิมพ์ **Terminal** แล้วกด **Enter** จะมีหน้าต่างตัวหนังสือเล็ก ๆ เปิดขึ้นมา (ไม่ต้องตกใจ)
3. คัดลอกบรรทัดข้างล่างนี้ทั้งบรรทัด แล้ววางในหน้าต่างนั้น (กด **⌘ + V**)

   ```
   xattr -cr /Applications/yt-downloader.app
   ```

4. กด **Enter** ถ้าไม่มีข้อความอะไรขึ้นมา แปลว่าสำเร็จแล้ว
5. ปิด Terminal ได้เลย

### ขั้น 3 — เปิดแอป

1. เข้า Finder → **Applications** → ดับเบิลคลิก **yt-downloader**
2. ถ้ายังขึ้นเตือนว่าเปิดไม่ได้: คลิก  → **System Settings** → **Privacy & Security** → เลื่อนลงล่าง → กด **Open Anyway** แล้วเปิดแอปใหม่
3. ตอนเปิดครั้งแรก จะขึ้น **"กำลังตรวจสอบและอัปเดต yt-dlp..."** รอสักครู่ (ไม่เกิน 15 วินาที) เป็นเรื่องปกติ

## ใส่ไฟล์คุกกี้ (ทำครั้งแรก และทำซ้ำเมื่อโหลดไม่ได้)

YouTube ไม่ให้โปรแกรมโหลดคลิปถ้าไม่ได้ล็อกอิน เลยต้องใช้ "ไฟล์คุกกี้" ซึ่งเป็นเหมือนบัตรผ่านจากบัญชี YouTube ของเรา

### ขั้น 1 — ติดตั้งตัวช่วยใน Chrome

1. เปิด Chrome แล้วค้นใน Google ว่า **Get cookies.txt LOCALLY**
2. กดเข้าหน้า Chrome Web Store ของตัวนั้น → กด **Add to Chrome** → กด **Add extension**
3. คลิกไอคอน **จิ๊กซอว์ 🧩** มุมขวาบนของ Chrome → กดรูป **เข็มหมุด** ข้าง Get cookies.txt LOCALLY ให้มันโผล่บนแถบตลอด

### ขั้น 2 — ล็อกอิน YouTube

1. ใน Chrome เข้า **youtube.com**
2. ดูมุมขวาบน ถ้าเห็นปุ่ม **Sign in** ให้กดแล้วล็อกอินด้วย Gmail ของตัวเอง (ถ้าเห็นรูปโปรไฟล์แล้ว ข้ามได้)

### ขั้น 3 — สร้างไฟล์คุกกี้

1. ขณะอยู่ที่หน้า youtube.com คลิกไอคอน **Get cookies.txt LOCALLY**
2. กดปุ่ม **Export**
3. จะได้ไฟล์ชื่อประมาณ **cookies.txt** อยู่ในโฟลเดอร์ **Downloads**

### ขั้น 4 — ใส่ไฟล์ในแอป

1. กลับมาที่ yt-downloader → กดปุ่ม **"เลือกไฟล์ cookies.txt"**
2. เลือก **Downloads** → คลิกไฟล์คุกกี้ที่เพิ่งได้ → กด **Open**
3. แอปจะขึ้นว่า **"บันทึกไฟล์คุกกี้แล้ว พร้อมใช้งาน"** เป็นอันเสร็จ

> ⚠️ **ห้ามส่งไฟล์คุกกี้ให้ใคร** ใครได้ไฟล์นี้ไปจะเข้าบัญชี YouTube/Gmail ของเราได้ ใส่ในแอปเสร็จแล้ว ลบไฟล์ใน Downloads ทิ้งได้เลย (แอปเก็บสำเนาไว้ให้แล้ว)

## โหลดคลิป (ทำทุกครั้งที่ใช้)

ปุ่มลัดในส่วนนี้: Windows ใช้ **Ctrl** / Mac ใช้ **⌘ (Command)**

1. **คัดลอกลิงก์:** เปิดคลิปใน YouTube → กด **Share (แชร์)** ใต้คลิป → กด **Copy (คัดลอก)**
   - หรือคลิกที่ช่องที่อยู่เว็บด้านบน แล้วกด **Ctrl + C** / **⌘ + C**
2. **วางลิงก์:** ในแอป คลิกช่อง **"ลิงก์วิดีโอ"** → กด **Ctrl + V** / **⌘ + V**
3. กดปุ่ม **"ดึงข้อมูล"** แล้วรอสักครู่ จะเห็นชื่อคลิปขึ้นมา
4. กดช่อง **"ความละเอียด / ไฟล์เสียง"** แล้วเลือกตามตารางข้างล่าง
5. กดปุ่ม **"ดาวน์โหลด"** แล้วรอแถบสีวิ่งจนเต็ม
6. เมื่อขึ้น **"ดาวน์โหลดเสร็จแล้ว"** เปิดโฟลเดอร์ **Downloads** จะเจอไฟล์ที่ชื่อเหมือนชื่อคลิป

| อยากได้ | เลือก |
|---|---|
| วิดีโอคมชัด | ตัวเลขมากสุด เช่น **1080p (mp4)** (ตัวเลขยิ่งมาก ยิ่งชัด แต่ไฟล์ใหญ่และรอนานกว่า) |
| วิดีโอไฟล์เล็ก โหลดเร็ว | **720p** หรือ **480p** |
| เพลง / เสียงไว้ฟัง | **เสียงอย่างเดียว — MP3** |
| เสียงไว้ตัดต่องาน (ไฟล์ใหญ่กว่า MP3 ประมาณ 10 เท่า) | **เสียงอย่างเดียว — WAV** |

ถ้าคลิปยาว ปุ่มโหลดจะขึ้น **"กำลังแปลงไฟล์ให้เข้ากับโปรแกรมตัดต่อ..."** ตอนท้าย ให้รอจนเสร็จ อย่าปิดแอป

## ถ้าเจอปัญหา

| เจออะไร | ทำแบบนี้ |
|---|---|
| **Windows:** ขึ้นจอสีฟ้า "Windows protected your PC" | กด **More info** → **Run anyway** |
| **Windows:** ใส่คุกกี้ไม่สำเร็จ | ย้ายโฟลเดอร์ yt-downloader ไปไว้ที่ Documents หรือ Desktop (อย่าไว้ใน Program Files) |
| **Mac:** เปิดแอปไม่ได้ ขึ้นว่าแอปเสีย หรือ "cannot be opened" | ทำ **ติดตั้งบน Mac ขั้น 2** (คำสั่งใน Terminal) อีกครั้ง แล้วเปิดใหม่ |
| เคยโหลดได้ แต่วันนี้ขึ้น "ดาวน์โหลดไม่สำเร็จ" หรือ "ดึงข้อมูลไม่สำเร็จ" | คุกกี้หมดอายุ ทำ **ใส่ไฟล์คุกกี้ ขั้น 3–4** ใหม่ |
| ขึ้นว่า "ไม่พบไฟล์คุกกี้" | ทำ **ใส่ไฟล์คุกกี้** ทั้งหมด |
| ค้างที่ "กำลังตรวจสอบและอัปเดต yt-dlp..." นานเกิน 15 วินาที | เช็คว่าเน็ตต่ออยู่ แล้วปิดเปิดแอปใหม่ |
| ขึ้นว่ามีการดาวน์โหลดกำลังทำงานอยู่ | รอให้ตัวเดิมเสร็จก่อน |
| ใส่ลิงก์ Playlist แล้วได้คลิปเดียว | ปกติ แอปโหลดทีละคลิป ต้องใส่ลิงก์ทีละคลิป |
| ลองหลายอย่างแล้วยังไม่ได้ | แคปหน้าจอส่งมาให้คนที่ส่งแอปให้ (Windows: **Win + Shift + S** / Mac: **⌘ + Shift + 4** แล้วลากคลุมส่วนที่ต้องการ) |

ส่วนใหญ่ปัญหามาจากคุกกี้หมดอายุ ถ้าวันหนึ่งโหลดไม่ได้ ให้ลองทำ **ใส่ไฟล์คุกกี้** ใหม่ก่อนเสมอ

## อัปเดตเป็นเวอร์ชันใหม่

ถ้าเปิดแอปแล้วเห็นข้อความ **"มีเวอร์ชันใหม่ ... กดเพื่อโหลด"** ด้านบน ให้กดแล้วโหลดไฟล์ให้ตรงกับเครื่อง (เหมือนตอนติดตั้งครั้งแรก) แล้วทำตามนี้ ไม่ต้องใส่คุกกี้ใหม่

- **Windows:** ปิดแอปก่อน → แตกไฟล์ zip ใหม่ไปที่**โฟลเดอร์เดิม** (เช่น Documents) → ถ้าถามว่าจะแทนที่ไฟล์ไหม กด **Replace (แทนที่)**
- **Mac:** ปิดแอปก่อน → ลากแอปใหม่ไปวางที่ **Applications** → ถ้าถาม กด **Replace (แทนที่)** → ทำ **ติดตั้งบน Mac ขั้น 2** (คำสั่งใน Terminal) อีกรอบ

ไม่ต้องห่วงเรื่อง YouTube เปลี่ยนระบบ ตัวโหลด (yt-dlp) อัปเดตตัวเองทุกครั้งที่เปิดแอปอยู่แล้ว

## ถอนการติดตั้ง

ปิดแอป yt-downloader ก่อน คลิปที่โหลดไว้ใน **Downloads** ไม่หายไปไหน

### Windows

1. ลบโฟลเดอร์ **yt-downloader** ที่แตกไฟล์ไว้ (ใน Documents หรือ Desktop) — ไฟล์คุกกี้อยู่ในโฟลเดอร์นี้ จะถูกลบไปด้วย
2. ถ้าเคยสร้างไอคอนบน Desktop ให้ลบไอคอนนั้นทิ้ง
3. ลบข้อมูลที่แอปเก็บไว้: กด **Win + R** → พิมพ์ `%APPDATA%` → กด **Enter** → ลบโฟลเดอร์ **yt-downloader**
4. ล้างถังขยะ (Recycle Bin)

### Mac

1. เปิด Finder → **Applications** → ลาก **yt-downloader** ไปที่ **Trash (ถังขยะ)**
2. ลบข้อมูลที่แอปเก็บไว้ **(สำคัญ — ไฟล์คุกกี้อยู่ที่นี่)**: ใน Finder กด **⌘ + Shift + G** → วางบรรทัดนี้แล้วกด **Enter**

   ```
   ~/Library/Application Support/yt-downloader
   ```

   จะเปิดโฟลเดอร์ขึ้นมา → กดลูกศรย้อนกลับ (หรือ **⌘ + ↑**) ขึ้นไปหนึ่งชั้น → ลากโฟลเดอร์ **yt-downloader** ไปที่ Trash
3. ล้างถังขยะ (คลิกขวาที่ Trash → **Empty Trash**)

### ถ้าไม่ใช้ตัวช่วยใน Chrome แล้ว (ทั้งสองระบบ)

คลิกไอคอน **จิ๊กซอว์ 🧩** มุมขวาบนของ Chrome → กด **⋮** ข้าง Get cookies.txt LOCALLY → **Remove from Chrome**

## สำหรับนักพัฒนา

แอป Electron ที่เรียก [yt-dlp](https://github.com/yt-dlp/yt-dlp) และ [ffmpeg](https://ffmpeg.org/) ซึ่ง bundle อยู่ใน `bin/` (ไม่ได้ commit ไว้)

- Windows: วาง `yt-dlp.exe` และ `ffmpeg.exe` ใน `bin/` แล้ว `npm ci` → `npm start` หรือ `npm run dist` (ได้ `dist/win-unpacked/`)
- GitHub Actions (`.github/workflows/build-mac.yml`) build Windows, Mac arm64 และ Mac x64 ทุกครั้งที่ push `main` (ไฟล์อยู่ใน artifacts ของแต่ละ run)
- ออกเวอร์ชันใหม่: แก้ `version` ใน `package.json` → commit → `git tag vX.Y.Z` → `git push origin main vX.Y.Z` แล้ว CI จะสร้าง Release ให้เอง แอปเวอร์ชันเก่าจะเห็นข้อความแจ้งเตือนตอนเปิด
